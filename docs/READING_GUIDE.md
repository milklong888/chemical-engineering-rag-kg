# 怎么读取这份知识库

这份库面向已有化工基础的读者和模型。验收标准是：读完一块，能无歧义复述它讲什么、怎么用以及必要条件。不是基础教程，也不是当前工程项目的参数表。

## 最短阅读路径

先选批次：[四源包](../knowledge/curated-four-books-v1/) 或 [化工原理上册包](../knowledge/curated-s001-upper-v1/)。查询时使用 `--bundle` 指定包；省略时仍查询四源包，不是自动搜索全部批次。

1. 先确定问题属于化工原理还是反应工程，再按来源卷、章节或主题组定位。
2. 阅读命中的**完整知识单元**：标题、正文、适用条件、单位/基准及来源页一起读。检索片段只负责定位，不应截取一句当成完整结论。
3. 需要解释邻近概念时才沿关系补读。`related_to` 表示有关联，不自动表示因果、计算先后或可以互相替代。
4. 涉及实际数值、经验关联式、设备曲线或材料限值时，回到当前项目和可合法核对的来源确认。教材示例、其他项目的值及已过时标准不能直接带入。

## 这些状态不能混用

- 一条知识被接纳，不代表整本书全文已经数字化完成。
- 页码和源文件哈希可以定位版本，但源文件哈希不是某张页图的哈希。
- 外部 Skills 引用是跨项目参考，不代表对应内容已经复制到本图谱。
- `cross_bundle_references` 是同项目不同批次间的关联。按目标批次、目标 KU 和正文哈希核对后补读；它不是本包内部图边，也不是自动合并检索。
- 向量检索返回的是候选，不是自动认证的工程答案；不相关或缺关键条件时应继续查证。
- 当前查询没有自动无答案阈值，库外问题也可能返回 top-k 候选；调用方仍须判断内容能否完整回答该问题。
- 公开开发用检索题只检查本批常见问法，不是封存测试集，不证明所有问题均能正确召回。

原始 PDF、页图和 OCR 全文不在公开库内。需要逐页复核时，审阅者须自行具备合法来源；不要在公开 Issue 中补传原件。

新增知识仍按 [入库准则](INGESTION_SPEC.md)：有实际增量才收，重复或无价值内容跳过。条件说清即可，不为检索分段另造细粒度知识节点。
