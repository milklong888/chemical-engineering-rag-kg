# 单对象内容贡献模板

复制下面内容填写即可。一个提交可以只解释或修正一个对象，不必生成向量或整套入库文件。不得附带未获准公开的原页、截图、OCR 全文或大段原文。

## 来源和范围

- 已有来源 ID；或新资料题名、版本及登记 Issue：
- PDF 页码（从 1 开始）；可选印刷页码：
- 章节/小节：
- 对象类型及原图号、表号、式号（没有就注明）：
- 对象 ID（已有时填写）：
- 本次类型：新增解释 / 纠错 / 补漏 / 边界或跨页关系修复
- 公开权限说明；来源核对方式（不填本机路径或私密链接）：

## 这段内容在讲什么

用自己的话说明对象、核心关系或结论，以及工程用途。长度以讲清楚为准，不需要扩写基础教程。

## 必要细节

只填写本对象适用的项目，不确定的注明待核对：

- 公式：表达式、主要变量、可见单位、条件。
- 表格：表题、关键字段与单位、如何查用；表体是否已完整转写/核对。
- 曲线：坐标、图例/参数、主要趋势、查读方式。
- 工程图/流程图：主要部件或步骤、连接/流向、关键标注。
- 续表/组合图：涉及页码及分段顺序，是否缺段或截断。

## 改动与不确定性

- 如果是纠错：旧内容哪里不对，本次改成什么：
- 已阅读的来源页及相邻上下文范围：
- 尚未核对、无法辨认或未完成的部分：
- 本次明确不处理的范围：

## 提交自查

- [ ] 说明对应实际来源，不是只看图号或检测标签生成。
- [ ] 没有猜测来源未给出的单位、条件或结论。
- [ ] 局部贡献没有宣称整章或全书已完成。
- [ ] 不含受保护原文载荷、密钥或本机绝对路径。

独立审阅、格式转换及正式入库由维护者继续处理；提交时不必预先勾选“审计通过”。
